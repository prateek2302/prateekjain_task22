# Task 20: Tailwind Hero Landing Page - Project Workspace

## Features
- **Tailwind CSS CDN Integration**: Built strictly using Tailwind CSS utility classes without external custom CSS stylesheets.
- **Sticky Navbar**: Configured with `sticky top-0 z-50` with backdrop blur and responsive links.
- **Hero Section**: Styled with headline hierarchy, description, and an orange-to-white gradient background (`bg-gradient-to-b from-orange-100 via-orange-50 to-white`).
- **Call-to-Action**: Dual CTAs ("Get AI free" and "Request a demo") with spacing and hover transitions.
- **Positioned Dashboard & Floating Cards**:
  - Parent container marked as `relative`.
  - Floating card 1: Tasks completed indicator.
  - Floating card 2: Status indicator ("On Track").
  - Floating card 3: Active team avatars with `+5 online`.
- **Fixed Chat Widget**: Positioned at `fixed bottom-6 right-6 z-50`.
